# Voice Recorder Meeting Record

Voice Recorder records WAV audio locally and offers optional offline transcription. Use it online: <https://livevoicerecorder.com/>. [Microsoft Store](https://apps.microsoft.com/detail/9PJ42F63QJ4M) · [Firefox Add-ons](https://addons.mozilla.org/firefox/addon/voice-recorder-meeting-record/)

The Debian package and AppImage come with detached signatures and SHA256SUMS. The app records WAV files locally and offers optional offline transcription, and the Ubuntu 24.04 package requires libssl3t64. The prior Debian launch used software rendering and virtual input, while AppImage launch and recording with a physical microphone remain untested.
